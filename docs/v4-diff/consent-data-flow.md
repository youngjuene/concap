# 연구 참여 자료의 처리와 국외 이전 안내

*(IRB 동의서 첨부용, 1쪽. [대괄호] 안은 연구자가 채웁니다.)*

이 연구는 웹 브라우저에서 진행됩니다. 참여 중에 생기는 응답 기록이 어디로 가고, 누가 무엇을 받으며, 언제 지워지는지를
아래에 정리했습니다. 기록에는 **이름·연락처·이메일이 들어가지 않습니다.** 연구자가 정해 준 **참여자 번호(예: P12)** 로만
구분되며, 이름과 번호의 대응표는 연구자만 종이로 보관합니다.

## 1. 자료가 지나가는 길

참여자의 브라우저 → **Vercel**(웹 서버, 싱가포르) → **Neon**(데이터베이스, 싱가포르) → 연구실 컴퓨터(분석용, 대한민국)

- 영상과 정지 화면은 **Vercel Blob**에서 브라우저로 보내집니다. 영상 쪽으로는 참여자 기록이 가지 않습니다.
- 자막을 새로 쓸 때는 **Anthropic**(Claude API, 미국)에 아래 3번의 내용만 보냅니다.

## 2. 저장되는 기록 (Neon, 싱가포르)

- 참여자 번호, 화면별 응답(선택한 보기, 점수, 화면에서 고른 위치), 응답 시각
- 영상 재생 기록(재생 위치, 일시정지), 2단계 조절 막대의 설정, 화면에 보인 자막과 그 시간
- 연구용 앱은 IP 주소나 브라우저 정보를 기록하지 않습니다. 다만 Vercel은 서비스 운영을 위해 요청 경로와 브라우저 종류를 담은
  실행 기록을 **1시간** 보관합니다.

## 3. Anthropic(Claude API)에 보내는 내용

- **보내는 것:** 영상 자막의 원문, 참여자가 고른 소리 보기의 이름, 응답 점수에서 만든 강조 문장, 1단계 점수의 평균과 가장
  주의를 기울인 소리 종류, 2단계 조절 막대에 맞춘 작성 지시
- **보내지 않는 것:** 참여자 번호, 세션 번호, 이름, 직접 입력한 글
- Anthropic은 API로 받은 입력과 출력을 **30일 안에 삭제**하며, 기본 설정에서 **모델 학습에 쓰지 않습니다.** 이용 정책 위반을
  확인해야 하거나 법이 요구할 때만 더 오래 보관할 수 있습니다(Anthropic Privacy Center, 2026-10-28 확인).

## 4. 국외 이전 내용

| 받는 곳 | 나라 | 받는 항목 | 목적 | 보관 기간 |
|---|---|---|---|---|
| Vercel Inc. | 싱가포르(서버) | 요청 경로, 브라우저 종류 | 웹 서비스 운영 | 1시간 |
| Neon | 싱가포르 | 2번의 기록 전부 | 연구 자료 저장 | [연구 종료 후 ○개월까지] |
| Anthropic, PBC | 미국 | 3번의 내용 | 자막 작성 | 30일 이내 삭제 |

이전 시점과 방법: 참여하는 동안 인터넷(암호화된 HTTPS 연결)으로 바로 보내집니다.

## 5. 보관, 삭제, 참여 철회

- 연구 자료는 연구실 컴퓨터로 옮겨 [연구 종료 후 ○년]까지 보관한 뒤 지웁니다. Neon의 기록은 [옮긴 뒤 ○개월 안에] 지웁니다.
- 참여 중이든 끝난 뒤든 언제든 철회할 수 있고, 불이익은 없습니다. 연구자에게 알리면 그 참여자 번호의 기록을 Neon과 연구실
  컴퓨터에서 모두 지웁니다. Anthropic에 보낸 내용은 참여자 번호가 없어 따로 찾을 수 없지만, 30일 안에 삭제됩니다.
- 국외 이전에 동의하지 않으면 이 웹 방식으로는 참여할 수 없습니다. [대신 할 수 있는 참여 방법이 있으면 적습니다.]
